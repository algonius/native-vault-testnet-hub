# Source Serif 4

Unmodified Latin and Vietnamese WOFF2 subsets from the Test marketing website's Source Serif 4 font, retrieved on 2026-10-02. The Hub footer uses weights 400 and 500, matching the reference introduction and wordmark. Font subsets are served locally so lettering does not depend on a third-party font request. CJK falls back to installed system fonts.

- Latin: https://test.algonius.ai/_next/static/media/68d403cf9f2c68c5-s.p.012bmydply3go.woff2
- Vietnamese: https://test.algonius.ai/_next/static/media/753b6407f468151f-s.p.11jlrhjosin9v.woff2
- Original font: https://fonts.google.com/specimen/Source+Serif+4
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/sourceserif4/OFL.txt

Distributed under the SIL Open Font License 1.1 in OFL.txt. Font files are unmodified.

CSS uses the private family name `Algonius Footer Serif` to avoid collisions with external font stylesheets. Asset names include their SHA-256 prefixes for cache separation.
